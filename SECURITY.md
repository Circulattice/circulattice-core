# Reporting a security concern

Send a private report to **security@lists.lfdecentralizedtrust.org**. Identify `Circulattice/circulattice-core`, the affected revision, the observed behavior and a minimal synthetic example. Keep vulnerability details and financial records out of public issues. This route and the coordinated disclosure process are documented in the [LF Decentralized Trust security policy](https://lf-decentralized-trust.github.io/governance/governing-documents/security/).
