## Duties and succession

Repository maintainers review issues and pull requests, verify changes to financial assumptions and comparison methods, triage reports using the security policy, and coordinate Lab updates with the LFDT Technical Advisory Council.

A contributor can nominate themself or another contributor through a pull request to this file. Include examples of sustained contributions or reviews, the proposed scope, contact details, and the nominee's agreement. Invite community review. A maintainer with authority for the repository records the decision and arranges the corresponding GitHub team update. A current maintainer can request emeritus status using the same process. Document other proposed changes in responsibility with reasons and give the affected person an opportunity to respond. An emeritus maintainer can seek reactivation by the same nomination process. [LFDT maintainer requirements](https://lf-decentralized-trust.github.io/governance/governing-documents/MAINTAINERS-file/)
